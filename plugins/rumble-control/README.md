# Rumble Control

> Control vibration intensity and motors on your handheld via InputPlumber

Adjust vibration intensity (Off/Low/Med/High), enable/disable left/right motors individually, and test the rumble with a short impulse. Works with devices that expose `Rumble` output capability through InputPlumber.
